# Player29 Website

Public website for Player29, a founder-led UK digital product company.

This repository is being built as a Next.js (App Router) application with TypeScript and Tailwind CSS, intended for deployment on Vercel.

## Requirements

- Node.js 20 or later
- npm 10 or later

## Development

```bash
npm install
cp .env.example .env.local
npm run dev
```

The local server listens on port **43129**.
